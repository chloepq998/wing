# wing — 날개: 아내 루트

이상의 『날개』를 새롭게 해석한 인터랙티브 스토리 게임 (아내 루트). 학교 발표용, 웹 브라우저 기반, 16:9, 클릭/터치 조작.

## 실행 방법

빌드 과정 없는 순수 정적 사이트입니다. `index.html`을 브라우저로 열거나, 로컬 서버로 띄우면 됩니다.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

Vercel에는 별도 설정 없이 정적 사이트로 그대로 배포됩니다.

## 구조

```
index.html          레이아웃 (게이지 / 배경·캐릭터 무대 / 대사창)
css/style.css        스타일
js/data.js           ★ 기획 데이터 — 씬, 대사, 선택지, 인내심 변화량, 엔딩 분기
js/engine.js          엔진 — 씬 진행 로직 (수정 불필요)
assets/characters/    캐릭터 일러스트
assets/backgrounds/   배경 이미지
```

## 스토리/대사 수정 방법

`js/data.js` 파일만 수정하면 됩니다. 씬, 대사, 선택지, 인내심 변화량, 엔딩 분기 조건이 모두 이 파일 하나로 관리됩니다 (하드코딩 없음). 파일 상단 주석에 각 필드의 의미가 설명되어 있습니다.

현재 `js/data.js`에는 실제 기획 대사가 아직 반영되지 않은 **임시 텍스트**(`[ ]`로 표시)가 들어 있습니다. 기획자 원고가 확정되면 해당 부분을 교체하면 됩니다.
